## Minestart sur téléphone

- **Android 8 ou plus récent** (WebView système à jour) : télécharge **`Minestart.apk`** et ouvre-le sur ton appareil. C’est une installation directe, pas une publication sur Google Play. Le jeu est inclus dans l’application et ne demande pas d’accès à Internet.
- **iPhone et iPad** : la version web installable s’ajoute à l’écran d’accueil depuis Safari (**Partager → Sur l’écran d’accueil → Ajouter**). Ouvre-la une fois en ligne et attends **Prêt hors ligne**. L’archive **`Minestart-PWA.zip`** contient le site à déployer sur une adresse HTTPS : ce n’est pas un fichier `.ipa`. La mise en ligne permanente sur GitHub Pages nécessite d’activer Pages pour le dossier `docs/` de la branche de travail.

Les deux versions conservent **Créatif**, **Survie**, le catalogue de 29 blocs et les sauvegardes locales. Glisse sur le paysage pour regarder, utilise les flèches pour avancer et les boutons pour miner, poser et sauter. En Survie, maintiens **Miner** pour récolter et utilise **Poser** sur un buisson pour récupérer des baies.

Ce premier APK utilise une signature de distribution ponctuelle. Une version ultérieure signée avec une autre clé ne pourra pas être installée par-dessus (désinstaller efface les mondes locaux).

Pour Windows, utilise toujours la [release Windows](https://github.com/azzoxMXYT/Minestart/releases/tag/v1.1.0).
