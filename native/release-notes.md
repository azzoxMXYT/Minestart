## Télécharger et jouer

- **Minestart.exe** : pour les PC **Windows 10 ou 11, 64 bits (Intel ou AMD)**.
- **Minestart-arm64.exe** : pour les PC Windows **ARM64**.
- **Minestart.html** : version autonome à ouvrir directement dans un navigateur, si ton PC n’autorise pas les `.exe`.

Double-clique sur le fichier, puis sur **Jouer**. Le jeu est inclus dans le lanceur et fonctionne hors ligne, sans installation. Le `.exe` ouvre une fenêtre Edge dédiée lorsqu’Edge est installé, sinon le navigateur par défaut. Ces exécutables ne sont pas signés. Les sommes de contrôle sont dans `SHA256SUMS.txt`.

Explore le monde de blocs, construis avec huit matériaux et sauvegarde tes constructions localement. Sur un PC plus lent, active **Mode éco** dans **Toutes les commandes**. Si WebGL est indisponible, le jeu passe en vue 2D.
