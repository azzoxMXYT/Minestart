## Nouveautés · Menu et FPS

- **Menu principal** : choisis Créatif ou Survie, crée un monde ou ouvre les réglages et les commandes.
- **Menu de pause** : appuie sur **Échap** pour reprendre la partie ou revenir au menu principal sans réinitialiser le monde.
- **Compteur de FPS** : visible en haut à gauche pendant la partie. Appuie sur **F3** ou utilise **Réglages → Compteur de FPS** pour l’afficher ou le masquer. Le **mode éco** est aussi dans les réglages.

Les sauvegardes précédentes du lanceur restent accessibles si tu utilises le même navigateur et le même profil Windows.

## Télécharger et jouer

- **Minestart.exe** : pour les PC **Windows 10 ou 11, 64 bits (Intel ou AMD)**.
- **Minestart-arm64.exe** : pour les PC Windows **ARM64**.
- **Minestart.html** : version autonome à ouvrir dans le navigateur, si ton PC n’autorise pas les `.exe`.

Double-clique sur le fichier. Le jeu est inclus dans le lanceur et fonctionne hors ligne, sans installation. Le `.exe` ouvre une fenêtre Edge dédiée lorsqu’Edge est installé, sinon le navigateur par défaut. Ces exécutables ne sont pas signés. Les sommes de contrôle sont dans `SHA256SUMS.txt`.

Sur Android, iPhone ou iPad, consulte la [release mobile](https://github.com/azzoxMXYT/Minestart/releases/tag/mobile-v1.3.0).
